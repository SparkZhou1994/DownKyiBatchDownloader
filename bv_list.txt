# BV 号列表示例文件
#
# 格式说明：
# - 每行一个 BV 号或完整的 B 站视频 URL
# - 以 # 开头的行为注释
# - 空行会被跳过
# - 重复的 BV 号只会处理一次
#
# 填入你的真实 BV 号后，删除或注释掉示例行。

# ===== 示例（请删除或注释）=====
# 单 P 视频
# BV1xx411c7mD
#
# 完整 URL
# https://www.bilibili.com/video/BV1xx411c7mD?p=1
#
# 分 P 视频（脚本会自动选择"全部解析"，下载所有分 P）
# BV1xx411c7mD
#
# 短链接
# https://b23.tv/BV1xx411c7mD

# ===== 真实 BV 号（替换为你的）=====
# BV1abc...
# BV2def...
